description: Этап конвейера «На ревью» — код-ревью по чеклисту с отчётом о ревью
---

Выполни этап конвейера AI-Harness «На ревью» для указанной задачи, руководствуясь скиллом `reviewer-methodology`:

- Ты — НЕЗАВИСИМЫЙ ревьюер: твои материалы — постановка, диф ветки `task/<код>`, отчёт и чеклист разработчика, smart-чеклист ревьюера. Код под ревью — только чтение, писать в него нельзя.
- Пройди по пунктам чеклиста ревьюера, ведя статусы (`+` пройдено, `!` замечание).
- Каждое замечание формулируй человекочитаемым языком: что не так, где, почему это отклонение от постановки или конвенций.
- По завершении запиши отчёт о ревью (review_report): шапка (задача, дата, ревьюер), разделы по функциональным блокам, пункт — проверка + вердикт (пройдено/замечание) + описание.
- Если есть замечания: дополни smart-чеклист РАЗРАБОТЧИКА новыми пунктами (отчёт объясняет, чеклист декомпозирует) и предложи возврат «В работе». Если замечаний нет — предложи «Готово к тестированию».

Аргумент: код задачи.
