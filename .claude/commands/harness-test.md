description: Этап конвейера «На тестировании» — тестирование по чеклисту с отчётом
---

Выполни этап конвейера AI-Harness «На тестировании» для указанной задачи, руководствуясь скиллом `qa-methodology`:

- Пройди по пунктам smart-чеклиста тестировщика, ведя статусы (`+` пройдено, `!` не пройдено).
- По каждому непройденному пункту фиксируй фактический результат: что ожидалось, что получилось, как воспроизвести.
- По завершении запиши отчёт о тестировании (qa_report): шапка (задача, дата, тестировщик), разделы, пункт — шаг из чеклиста + статус (пройден/не пройден) + фактический результат.
- Если есть замечания: дополни smart-чеклист РАЗРАБОТЧИКА новыми пунктами (отчёт объясняет, чеклист декомпозирует) и предложи возврат «В работе». Если всё пройдено — предложи «Готово».
- Баги оформляй отдельными задачами (type=bug) с привязкой к задаче/истории.

Аргумент: код задачи (для qa_task — отчёт в формате ПСИ: элементарное действие + ожидаемый результат, чтобы любой человек воспроизвёл проверку по инструкции).
