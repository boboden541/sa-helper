Выполни этап конвейера AI-Harness «Готово к тестированию» (подготовка проверки), руководствуясь скиллом `qa-preparation`:

- Прочитай постановку задачи, чеклист и отчёт разработчика, отчёт ревью с его чеклистом.
- Опирайся на верхнеуровневые абстракции проекта (API-методы, таблицы, интерфейс): план проверяет наблюдаемое поведение, а не код.
- Составь smart-чеклист тестирования (checklist_kind=tester): сценарий по каждому пункту постановки (шаги + ожидаемый результат), негативные проверки, краевые случаи из отчёта ревью, регресс затронутой функциональности.
- Каждый пункт — воспроизводимый шаг: действие человекочитаемым языком + наблюдаемый ожидаемый результат.
- Само тестирование не проводи — это следующий этап.

Аргумент: код задачи.
