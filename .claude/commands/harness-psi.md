---

Выполни этап конвейера AI-Harness «На тестировании» для указанной ИСТОРИИ, руководствуясь скиллом `psi-methodology` (ПСИ-составитель):

- Прочитай постановку истории, чеклисты и отчёты всех задач истории.
- Составь документ ПСИ: разложи функционал истории до элементарных действий; для каждого действия выпиши ожидаемый результат из требований.
- Структура: шапка (task-code истории, версия, дата, автор) → разделы (функциональные блоки) → пункты (№, действие, ожидаемый результат, статус прогона, фактический результат).
- Критерии качества: действие элементарно и воспроизводимо руками; ожидаемый результат наблюдаем и человекочитаем; покрытие функционала полное; ожидания не приукрашены против постановки.
- Ограничения: не меняй требования и не улучшай ожидаемые результаты против постановки.
- Сохраняй документ по psiPath задачи (или в файл проекта) и предлагай следующий шаг конвейера.

Аргумент: код истории.
