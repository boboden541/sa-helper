# Цветовая семантика mindmap-карт

> Ресурс скилла `mindmap-cartographer`. Правило: **одно цветовое измерение на карту**. Цвет отвечает на один вопрос/риск — тот, что заявлен в цели карты. Кодировать цветом два разных вопроса в одной карте запрещено.

---

## 1. Каноническая палитра (измерение «риск касания критичного хранилища»)

Каноническое измерение — «касается ли элемент критичного хранилища/ядра и как именно» (у корня карты — uat_db). Палитра владельца:

| HEX | Где применяется | Смысл |
|---|---|---|
| `#LightCyan` | L0 корень | сервис; НЕ кодирует измерение |
| `#FF9E9E` | L2 элемент (экран/шаг) | есть прямые вызовы ядра (SOAP/JDBC напрямую) |
| `#FFD5D5` | L2 элемент (экран/шаг) | касание только через прослойку (кэш интеграционного сервиса) |
| бесцветный | L2 элемент | критичное хранилище не касается вовсе |
| `#FFB3B3` | уровень канала | канал «напрямую» (SOAP ядра, JDBC) |
| `#FFE8CC` | уровень канала | канал через прослойку (кэш интеграционного сервиса) |
| `#FFDDDD` | уровень атома | атом лежит в критичном хранилище (uat_db) |
| `#E0E0E0` | L1 заглушка | вынесенная в part-N группа (декомпозиция) |

Оттенки согласованы: чем «горячее» элемент L2, тем прямее касание.

## 2. Правила применения

1. **Одно измерение на карту.** Измерение = главный вопрос/риск цели промта. Если в промте риска нет: сервис работает с несколькими хранилищами → измерение касания критичного хранилища; иначе карта строится без цветов и без legend.
2. **Legend обязательна при любом использовании цвета измерения** — блок `legend … end legend` в конце карты, заголовок `<b>ЛЕГЕНДА</b>`, одна строка на цвет. Технические заливки — `#LightCyan` корня и `#E0E0E0` заглушек part-N — измерение НЕ кодируют, в legend не расшифровываются и сами по себе legend не требуют: карта без измерения может состоять из одного корня `#LightCyan` без legend.
3. **Взаимная полнота:** каждый использованный в карте HEX измерения расшифрован строкой в legend; каждая строка legend соответствует реально используемому HEX. Бесцветность — тоже значение и тоже описывается строкой («бесцветный = не касается»).
4. Измерение фиксируется в мете обёртки (`**Цветовое измерение**: <…>`), альтернативные измерения — только с явной фиксацией.

## 3. Альтернативные измерения

Допустимы, если таков вопрос цели промта (палитру подбирает генератор, сохраняя правило «одно измерение + legend»):

- **Канал доступа** (REST / SOAP / JDBC / очередь / git).
- **Тип действия** (Чтение / ЗАПИСЬ) — когда карта о поверхностях записи.
- **Среда/контур** (prod / stage / внешний контур партнёра).

Выбранное измерение и палитра обязательно описываются в legend и в мете обёртки.
