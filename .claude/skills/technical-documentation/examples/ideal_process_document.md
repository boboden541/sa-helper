## 3. Activity-диаграмма (основной сценарий)

> Формат строго **PlantUML**. `partition` — по участникам; все ветвления — `if/else`; параллельные шаги — `fork`. Надписи на русском, техимена в скобках.

```plantuml
@startuml
start
partition "{Участник 1}" {
  :{Шаг 1: бизнес-смысл} ({Controller::action});
  :{Шаг 2: бизнес-смысл} ({Service::method});
}
partition "{Участник 2}" {
  if ({Условие ветвления}?) then (Да)
    :{Шаг 3а};
  else (Нет)
    :{Шаг 3б};
  endif
}
:{Финальный шаг: результат процесса};
stop
@enduml
```

## 4. Sequence-диаграмма

> Межкомпонентное взаимодействие основного сценария. На стрелках — `METHOD /path` (или имя очереди/события) и русское описание. `note` — примеры ключевых DTO.

```plantuml
@startuml
actor "Пользователь" as user
participant "{Наш сервис}" as svc
participant "{Смежный сервис}" as ext
database "{DB_NAME}" as db

user -> svc : {действие} ({METHOD /path})
svc -> db : {SQL_QUERY} (чтение данных для процесса)
db --> svc : {данные}
svc -> ext : {METHOD /path}\n(бизнес-смысл вызова)
note right
  {пример ключевого DTO}
end note
ext --> svc : {ответ}
svc --> user : {результат}
@enduml
```
