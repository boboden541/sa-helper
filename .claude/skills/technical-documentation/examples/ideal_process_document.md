## 3. Activity-диаграмма (основной сценарий)

> Формат строго **PlantUML**. `partition` — по участникам; все ветвления — `if/else`; параллельные шаги — `fork`. Надписи на русском, техимена в скобках.

```plantuml
@startuml
start
partition "{Участник 1}" {
  :{Шаг 1: бизнес-смысл} ({Controller::action});
  :{Шаг 2: бизнес-смысл} ({Service::method});
}
partition "{Участник 2}" {
  if ({Условие ветвления}?) then (Да)
    :{Шаг 3а};
  else (Нет)
    :{Шаг 3б};
  endif
}
:{Финальный шаг: результат процесса};
stop
@enduml
```

## 4. Sequence-диаграмма

> Межкомпонентное взаимодействие основного сценария. На стрелках — `METHOD /path` (или имя очереди/события) и русское описание. `note` — примеры ключевых DTO.

```plantuml
@startuml
actor "Пользователь" as user
participant "{Наш сервис}" as svc
participant "{Смежный сервис}" as ext
database "{DB_NAME}" as db

user -> svc : {действие} ({METHOD /path})
svc -> db : {SQL_QUERY} (чтение данных для процесса)
db --> svc : {данные}
svc -> ext : {METHOD /path}\n(бизнес-смысл вызова)
note right
  {пример ключевого DTO}
end note
ext --> svc : {ответ}
svc --> user : {результат}
@enduml
```

## 8. Пример: сквозной прогон на тестовых данных

> Обязателен для каждого process-документа: документ «оживает» на конкретных значениях. Глубина прогона: дословные запросы — для ключевых и нетривиальных веток; остальные шаги — кратко.

### 8.0 Карта процесса для аналитика: только вызовы API и обращения к данным

> Activity-диаграмма ОДНОГО представительного пути (типовой или худший сценарий), не всей траектории — за всю траекторию отвечает раздел 3. Каждый узел — конкретный вызов (`METHOD /path`, SQL/хранимка, обращение к очереди/файлу — форма определяется стеком проекта), без бизнес-прозы. ЗАПИСИ подсвечены `#pink`. `note` — дословные форматы запрос/ответ. Нумерация узлов своя; синхронность с разделом 5 не требуется (другой срез).

```plantuml
@startuml
title {Представительный путь: суть}
start
:{N}. {вызов} — {суть};
:{N}. {чтение: SQL / API / очередь};
if ({Условие}?) then (да)
  #pink:{N}а. {запись: SQL / API};
  note right
    **Запрос:** {параметры}
    **Ответ:** {результат}
  end note
else (нет)
  :{N}б. {альтернатива};
endif
stop
@enduml
```
