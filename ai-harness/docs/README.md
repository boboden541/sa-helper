# AI-Harness: документация

| Папка / файл | Что внутри |
|:-------------|:-----------|
| `design/` | Дизайн-доки конвейера: эволюция v1 → v2 → v3, проект handoff-конвейера, сравнение с эталоном [aif-handoff](https://github.com/lee-to/aif-handoff) |
| `acceptance.md` | Протокол приёмки (этап 7, критерии СТ §3/§7) — отчёт «на дату» |
| `e2e-report.md` | Отчёт сквозного тестирования интерфейса (Playwright, живой стек :8088) — отчёт «на дату» |
| `design-review.md` | Дизайн-ревью: сверка интерфейса с макетом по DOM — отчёт «на дату» |
| `acceptance-data.json` | Машиночитаемые данные приёмки |

> Три отчёта фиксируют цифры на момент приёмки и не обновляются:
> актуальное состояние — git log и прогон тестов.
