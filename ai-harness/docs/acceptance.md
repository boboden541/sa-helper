## 4. Сквозной сценарий конвейера (живой)

Создание задачи через API → pending + уведомление модерации → форс-переходы по
конвейеру → Eve-команды с намерение→«да» → хроники/уведомления/очередь отвечают
(смок `scripts/smoke.py`). Полный цикл с реальным Claude-раннером (story → декомпозиция →
TDD → ревью → тестирование → ПСИ → M6) — при подключённом провайдере:
`pip install 'ai-harness[daemon]'` → `dev.py run-daemon`.
