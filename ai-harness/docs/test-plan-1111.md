# План верхнеуровневого тестирования доработок 11.11.2026

Цель: вручную убедиться, что исправления анализа 11.11 работают end-to-end.
Автоконтур уже зелёный (pytest 355+16, vitest 48, ruff/tsc/eslint/build) —
ниже то, что автотесты не видят: живой стек, браузер, docker-окружение.
Формат: действие → ожидаемый результат. ~40 минут на весь план.

## 0. Подготовка стенда

```bash
cd ai-harness
docker compose build backend frontend daemon
docker compose --profile daemon up -d
docker compose ps                # 5 контейнеров healthy
```

В логах backend при старте — применение миграций (alembic upgrade head
теперь выполняет контейнер, хостовый venv для схемы не нужен):

```bash
docker compose logs backend | grep -i alembic | tail -5
```
