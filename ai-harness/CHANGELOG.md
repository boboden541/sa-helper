# CHANGELOG

## 0.2.0 — 11.11.2026 (глубокий анализ: баги + продуктизация)

### Безопасность и аутентификация
- **API пользователей**: создание людей (`POST /auth/users`), смена пароля
  (`POST /auth/change-password`), включатель обязательного входа
  (`GET/POST /auth/required`) — раньше флаг `auth.required` нельзя было
  включить ниоткуда, единственная учётка была из сида.
- Cookie сессии: `max_age` по TTL, флаг `secure` — env `SESSION_COOKIE_SECURE`.
- CORS — env `BACKEND_CORS_ORIGINS` (был захардкожен dev-origin Vite).
- Порты backend/frontend/adminer — только на `127.0.0.1` (как postgres 04.11).
- restart-политики всем боевым контейнерам.
- Личные пути и внутренние имена убраны из UI и промтов (placeholders, Eve).

### Баги
- **env-гонка параллельных прогонов**: окружение провайдера уходит в опции
  SDK, `os.environ` процесса больше не перезаписывается чужим токеном.
- **Eve-interrupt гасил параллельного соседа**: легаси-вызов
  `release_reservation` закрывал ВСЕ прогоны задачи; перехват через Eve теперь
  идентичен каноническому (закрывает только последний прогон).
- **changedByOther**: флаг конфликта правки доезжает до фронта (тост работает).
- **Чеклист**: ошибка загрузки больше не превращается в пустой список; сохранение
  при незагруженном состоянии заблокировано (риск затирания).
- Удаление агента с историей — честный 400 со списком ссылок (был 500).
- Клон агента копирует назначенные скиллы.
- StoryPicker ищет только истории (параметр `type` вместо игнорировавшегося `types`).
- Дельта-брифинг ПСИ нумерует пункты по документу (П.N), а не по подмножеству.
- Публикация flow отвергает миграцию в несуществующий статус (был невозвратный 500).
- `rework.cycle_limit` без сида — дефолт 5 (был NoResultFound 500).
- git quotepath: кириллица в porcelain больше не ломает keep_paths; rename-записи.
- Мусор в путевых UUID — 400 по всему семейству эндпоинтов (были 500).
- Истёкшие сессии чистятся retention-тиком (таблица `session` росла вечно).
- Рестарт моста LiteLLM — вне event loop демона.
- Лестница ретраев переживает пустой/мусорный `daemon.retry_pauses_minutes`.
- Утечка слота `max_parallel` при сбое в except-пути закрыта (try/finally).
- Поиск доски: устаревший ответ не перезаписывает свежий; Eve не шлёт второй
  запрос во время стрима; `JSON.parse` localStorage защищён.

### Инфраструктура
- `sqlalchemy>=2.1` (код использует `distinct_on`; на 2.0 демон не стартовал).
- `constraints.txt` — зафиксированные версии проверенного окружения.
- `npm ci` в сборке фронтенда (строго по lock-файлу).
- **Миграции применяются при старте backend-контейнера** (venv на хосте больше
  не обязателен).
- `scripts/backup.sh` — бэкап postgres (стратегии не было вовсе).
- Версия приложения читается из метаданных пакета (единый источник — pyproject).
- Git: сборочный мусор фронтенда не трекается; `docs/postmortems.md` — карта
  инцидентов из комментариев.

### Тесты
- +16 регресс-тестов анализа (backend + daemon): env-гонка, Eve-interrupt,
  changedByOther, delete/clone агента, UUID 400, миграции flow, M4-дефолт,
  чистка сессий, лестница ретраев, API пользователей.
- +2 vitest: защита чеклиста от затирания, успешный путь сохранения.

### Известные ограничения (решения владельца)
- Анонимный вход и SQL-Eve — принятые риски (README §Безопасность).
- docker.sock и `${HOME}` в контейнерах — осознанная модель для локального
  использования; для многопользовательского деплоя требует пересмотра.
- e2e (29 сценариев) — локальный прогон, в CI не включён.
